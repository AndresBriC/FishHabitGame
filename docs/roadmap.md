# Roadmap

## Current milestone: playable fishing vertical slice

**Outcome:** A signed-in player can receive a daily pond, catch a fish, refresh the page, and see the result in their collection.

### In scope

- FastAPI backend and React frontend foundations.
- User registration and authentication.
- Fish catalog, daily pond, fishing attempts, and persistent catches.
- Pond and collection screens.
- Automated tests for core fishing rules.

### Explicitly deferred

- Habit creation, completion, and streaks.
- Items, bait, rods, rerolls, and rarity modifiers.
- PWA/offline support and push notifications.
- Social features, Discord, native mobile, and Godot.

## Later milestones

1. Habit loop and streaks.
2. Rewards, items, and collection depth.
3. UI polish, accessibility, and PWA support.
4. Production deployment and observability.
